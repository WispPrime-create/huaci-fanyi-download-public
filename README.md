# 划词翻译 · 下载

常驻 macOS 菜单栏的本地翻译小工具。这个仓库只用来发布安装包，不包含源代码。

下载页面：https://huaci-fanyi.vercel.app

在 [Releases](https://github.com/WispPrime-create/huaci-fanyi-download-public/releases/latest) 里有四个版本，区别只是首次打开时下载哪种本地模型：

| 文件 | 本地模型 |
| --- | --- |
| `TopBarTranslator-NoModel.zip` | 不下载模型，使用 Apple 翻译 |
| `TopBarTranslator-2B.zip` | 约 1.9 GB，适合 8 GB 内存 |
| `TopBarTranslator-4B.zip` | 约 3.3 GB，适合 16 GB 内存 |
| `TopBarTranslator-8B.zip` | 约 6.1 GB，16 GB 以上内存 |

这个 App 没有使用 Apple 开发者证书签名。首次打开时如果 macOS 提示无法验证开发者，请在“系统设置 → 隐私与安全性”中点击“仍要打开”。
